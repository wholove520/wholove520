# 协议共生跃迁论（Protocolal Symbiotic Transition Theory, PSTT）

一个可安装、可复用的 AI 技能包（Skill），用于历史演化分析、制度/组织/时局诊断、概率推演与治理策略设计。

## 这是什么

PSTT 是一套分层耦合的统一分析框架：

- **动力层（描述轴/实然）**：继承"系统跃迁史观"——历史是协议在熵增与冗余博弈中相变的过程，提供动力与相变语言。
- **方向层（规范轴/应然）**：叠加"可纠错共生主义"——相变方向必须由共生底线约束，提供伦理与底线约束。
- **落地层**：把约束转化为历史分析、制度诊断、治理设计、时局推演、组织与个人策略等可操作应用。

一句话定位：**协议演化提供动力，共生伦理提供方向，纠错机制提供稳定。**

## 核心内容速览

- **八条公理**：描述轴（生存先于本质、连接即权力、冗余即自由、自指涉即生命）+ 规范轴（共生即方向、责任对称、纠错即合法性、底线不可破）。
- **统一公式**：相变方程与锁定条件，核心约束 τ_I < τ_K（规则迭代速度 < 内核更新速度时系统锁定/退化）。
- **演化四阶段**：含退化形态、共生底线、纠错通道。
- **机制体系**：热切换、自噬、防火墙、纠错环及其耦合生态。
- **相变状态机**：五态（健康/僵化/锁定/濒临相变/相变）；**相变类型学**：六类路径。
- **治理结构**：五方共轭。
- **统一刻度测量**：熵值、冗余度、纠错速度、共生指数、协议健康度（PHI）。
- **多堆栈国际模型**：双核时代、外化冲突、吸附、底线竞争。
- **可检验命题**：P1–P4，含证伪条件。

## 使用方法（给 AI / Agent）

1. 将本目录作为一个 Skill 装入你的技能目录（保持 `SKILL.md` 与 `references/` 相对结构）。
2. 触发场景：用户提及"协议共生跃迁论""系统跃迁史观""系综协议主义""共生底线""纠错环""热切换""自噬""五方共轭""责任对称""多堆栈""协议退化"等术语，或要求"用这套理论分析/推演/诊断"某现象。
3. 工作流：先读 `references/framework.md` 以定义为准 → 定位分析对象（阶段/病理/事件层级/行动者）→ 按 `references/application-patterns.md` 对应模式组织输出。
4. **强制边界**：输出须区分实然/应然（规范轴为价值承诺，非客观事实）；涉及现实国家/政权的诊断须附"理论假设性推演，不代表现实客观结论"；推演默认排除突发外生冲击（AGI 奇点、全球灾难、全面热战），路径为概率排序而非必然结局。
