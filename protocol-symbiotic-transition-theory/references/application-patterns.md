# 应用模式（分析工作流模板）

> 本文件提炼理论在具体任务中的标准分析路径。使用时先读 `framework.md` 确定定义，再按场景套用本文件模板。

## 模式一：历史跃迁分析

**适用**：分析某文明/国家的历史演化、制度变革。

**步骤**：
1. 定位当前所处协议阶段（血缘/主权/资本/认知）及退化形态。
2. 识别亚稳态→相变的触发点（熵压来源：内耗、外部冲击、规则失效）。
3. 判断跃迁是否按热切换路径（寄生→并行→虹吸→退役）推进，标记未完成环节。
4. 若退化，判断是否越过不可逆临界点，评估外部手术可行性。

**输出结构**：阶段定性 → 跃迁路径逐环节核对 → 未完成/异常环节 → 演化张力。

## 模式二：制度现象根因分析

**适用**：分析具体社会乱象、行业痼疾、组织僵化问题的存在原因。

**步骤**：
1. 规则迭代速度差：新模式变异速度 vs 监管规则更新速度，找监管套利空间。
2. 节点冗余不对称：供需双方认知冗余、资源冗余的落差，找收割土壤。
3. 局部利益链固化：是否存在多节点共生的灰色子协议，是否逃避全局自噬。
4. 惩戒熵值不足：违规成本 vs 违规收益的比值，评估淘汰机制是否失效。

**输出结构**：现象定性（局部熵增）→ 四层成因 → 系统特征归因（外围代谢/内核自噬）。

## 模式三：治理方案设计

**适用**：用户问"如何根除/解决某乱象"。

**步骤**（五件套，按需裁剪）：
1. **穿透式规则**：按实质特征认定而非形式名目，堵死规避空间；建立"新模式触发式更新"。
2. **穿透式惩戒**：实控人终身禁入 + 关联主体全链条限制 + 惩罚性赔偿（违法成本≥3-5倍收益）。
3. **拆解利益链**：平台连带责任、属地考核挂钩，对齐全局激励。
4. **补认知冗余**：强制信息披露、统一风险提示、免费科普，缩小供需认知差。
5. **共轭监督**：行业自律 + 公益诉讼 + 公众举报通道，补监管信息盲区。

**治理结构按五方共轭落地**：算法揭示（透明可审计）+ 专家建设（限时）+ 公民否决（只否决不提案）+ 风险代言（谁扛险谁进协商）+ 责任对称（谁决策谁担后果）。三权永不聚合，两权必须对称。

**边界判断**：区分"可根除"与"系统代偿型只能控烈度"（乱象承接底层诉求时，系统倾向控烈度不根除）。

## 模式四：时局推演

**适用**：分析当前世界格局、国家博弈、地缘冲突的影响与走向。

**步骤**：
1. 定性事件层级：全局协议层 / 子协议层 / 局部摩擦层。
2. 判断烈度：是否击穿核心协议边界（如能源通道、主权本体、金融锚点）。
3. 评估冗余缓冲：全局冗余能否吸收冲击熵增（战略储备、替代链、风险定价）。
4. 评估格局约束：双栈/多栈均势是否抑制冲突外溢。
5. 判断可预期性：渐进慢熵增 ≠ 突发黑天鹅。

**输出结构**：事件层级定性 → 烈度/冗余/约束三查 → 是否触发相变的结论。

## 模式五：概率推演

**适用**：用户问"某事件/黑天鹅发生概率"。

**步骤**：
1. 先定义：全局黑天鹅 = 击穿核心协议、触发非预期相变的事件；区域/行业冲击不算。
2. 按时间维度分层给概率：短期(1-3年) / 中期(5-10年) / 长期(10年+)。
3. 列出核心浮动变量及对概率的修正方向（如"双栈共识→概率降15个百分点"）。
4. 标注前提：排除外生冲击；路径为概率排序非必然结局。

## 模式六：大众化转译

**适用**：用户要求把理论讲给非专业受众、做传播方案。

**步骤**：
1. 术语替换：用 `framework.md` 的大众化对照表替换全部学术术语。
2. 破圈切入：从日常痛点切入（职场内耗、物业规则、群聊矛盾），不聊宏大叙事。
3. 轻量落地：给出可即用模板（群规日落机制、小团队热切换工作法、只否决不提案讨论法）。
4. 安全边界：聚焦"减少规则内耗"的实用属性，不碰意识形态类议题。

## 模式七：组织/公司/个人策略设计

**适用**：用户问"一个组织/公司/个人该怎么用这套理论改造/发展"。

**步骤**：
1. **定位当前协议状态**：判断组织处于哪一协议阶段、退化形态、熵压来源；冗余与纠错通道是否充足。
2. **设计热切换路径**：确定新旧规矩的寄生→并行→虹吸→退役路线，标记未完成环节。
3. **补齐纠错环**：信息能上来、表达有实权、问责能落地、规则能更新；估算 τ_I 与 τ_K，确认 τ_I < τ_K。
4. **落地治理共轭**：算法揭示 + 专家建设 + 公民/风险否决 + 责任共轭；明确谁决策、谁担责、谁可否决。
5. **守住共生底线**：改造不得突破底线（不让人掉底等），淘汰规矩不淘汰人，给退出者过渡保障。

**输出结构**：现状定位 → 热切换路径 → 纠错环设计 → 治理结构 → 底线与保障。

**参考模板（公司改造五件套）**：公司宪章（自噬硬上限）+ 员工代表（风险否决/风险代言）+ 利润分享（责任对称）+ 匿名反馈（纠错环）+ 复盘红队（冗余）+ 退出保障（伦理底线）。

## 模式八：测量与诊断

**适用**：用户要求对某系统/组织/时局的"健康度"做量化或半量化诊断，或问"它会不会相变/何时相变"。

**步骤**：
1. **估算协议熵值 H** = 规则数量 × 执行偏差 × 反馈延迟，判断僵化程度。
2. **估算冗余度 R** = 退出选项 + 替代方案 + 资源储备，判断脆弱性。
3. **估算纠错速度 τ** = τ_I − τ_K：τ<0 健康；τ>0 锁定；τ≫0 濒临相变。
4. **评估共生指数 S** = 底线保障 + 机会公平 + 责任对称 + 表达实权。
5. **判定状态机相位**：健康态 / 僵化态 / 锁定态 / 濒临相变 / 相变，并指出对应的相变路径类型（六类）。
6. **给出相变概率排序** Pr(相变) = F(H, R, τ, S, Θ)，并列出浮动变量（Θ）。

**输出结构**：五项指标估值（含口径说明）→ 状态判定（五态 + 相变路径类型）→ 关键浮动变量 → 概率排序与前提标注。

> 口径声明：H/R/τ/S 为半定量诊断指标，需给出每项的口径与来源；相变概率为概率排序而非精确数值。

## 模式九：行动主体分析

**适用**：用户问"谁在推动/阻碍某相变""某方会不会成功/失败"。

**步骤**：
1. 识别角色：推动（新协议节点/冗余积累者/认知移民）、阻碍（既得利益固化者/防火墙滥用者）、投机（黑天鹅套利者）、裁判（算法揭示者/公民否决者）。
2. 估算行动者禀赋：连接密度、冗余储备、底线正当性、锁定收益。
3. 用效用公式排序：推动力 ≈ 连接密度×冗余×正当性；阻碍力 ≈ 连接密度×锁定收益×防火墙控制。
4. 评估策略匹配：推动者是否先积冗余再建节点；阻碍者是否靠吸纳+封禁+外包冲突。

**输出结构**：角色清单 → 禀赋估值 → 推动/阻碍力对比 → 成败关键变量。

## 模式十：跨尺度 / 多堆栈推演

**适用**：用户问"某格局长期会怎样""双核/多极走向"，或要求跨时间尺度分析。

**步骤**：
1. 声明时间尺度（短期/中期/长期/超长期），明确每尺度主导机制与干预手段。
2. 定性事件层级（全局协议/子协议/局部摩擦），判定六类相变路径。
3. 多堆栈场景：分析外化冲突、吸附、冗余竞争、底线竞争、相变耦合。
4. 用双栈稳定条件判断：双方冗余、底线互认、外化冲突是否受约束。
5. 分层给概率并列出浮动变量，标注前提。

**输出结构**：尺度声明 → 事件层级 → 相变类型 → 多堆栈动力学 → 分层概率与浮动变量。

## 模式十一：病理诊断与案例分析

**适用**：用户问"某系统哪里坏了/为什么僵化/会不会崩"，或要求历史/组织案例的机制解读。

**步骤**：
1. 四类病理排查：相变失败（热切换中断/半切换）、纠错失效（反馈梗阻/问责空转/规则硬化）、冗余耗尽（单一依赖/透支/私有化）、底线突破（滑坡/工具化/代偿）。
2. 定位病灶机制：哪一机制失效、哪条反馈断裂。
3. 判断是否越过临界点：可逆（热切换窗口）还是锁定（需自噬/外部手术）。
4. 按附录 A 档案格式输出案例记录，标注"理论推演/示意案例"。

**输出结构**：病理类型 → 病灶机制 → 可逆性判定 → 案例档案（含底线状态与教训）。

## 通用输出规范

1. 结构清晰：先结论后展开，用标题分层。
2. 术语统一：所有概念以 `framework.md` 定义为准。
3. 边界标注：涉及现实国家/群体的诊断必须附"理论假设性推演，不代表现实客观结论"。
4. 替代称呼：按用户要求使用替代称呼（如A国/B国、决策者），不直接使用现实称谓。
